# 主題單字擴充

參考來源：https://prepedu.com/zh-hant/blog/elementary-english-vocabulary ，查閱日 2026-10-08。

以頁面實際列出的 20 類、每類 10 筆詞彙為匯入範圍，並非完整 1200 字清單。不複製文章、例句、網站圖片或其分級宣稱；中文釋義依遊戲情境重新整理，圖片自行生成。

原有 60 字與 ID 保留；新增 175 字，共 235 個詞條、23 類。食物中的水果、節慶中的生日與蛋糕等共用詞條，可在不同主題練習，圖鑑去重。同一英文字有不同義（orange 顏色／水果）仍保留不同詞條。

使用者要求以單字為主，因此來源 next to 以同義單字 beside 取代；原始主題名單見 vocabulary-source-topics.json。其餘詞彙保留。來源 pen 以「原子筆」呈現以便區別鉛筆；police、far 等只提供語意，不沿用來源詞性標示。

人物、時間、位置、描述、尺寸、情感、家庭、學習與職業等情境可能無法只靠圖片分辨，因此聽音選圖附中文提示；看圖選英文也顯示中文語意。保留每輪五字、十題、三選一、不計時與無限重試，沒有難度選擇。

主題改為可搜尋的選擇視窗，可用分類名稱、英文單字或中文釋義查找。原圖鑑與貼紙 storage key 維持不變；新增音訊使用 Zira en-US、Hanhan zh-TW，單聲道 22050 Hz，離線 WAV。

圖片提示與來源見 vocabulary-source-art.json。所有新增資產列入 scripts/build.cjs，正式站須比對程式與各圖檔／音訊完整性後才交付。
