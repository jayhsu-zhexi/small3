# 首頁遊戲插畫入口

單字樂園採用森林小狐狸橫幅；其他 11 個獨立遊戲以兩欄插畫卡片呈現。圖片、類型、遊戲名稱、簡短玩法、開始入口整合成一個可點選連結，支援鍵盤焦點與減少動畫設定。

新增四份 imagegen 圖檔，提示與生成來源見 home-game-art-v1.json；轉為 WebP，總大小約 1.44 MB，列入 scripts/build.cjs 的正式版資產清單。三份封面圖集使用等分 2×2 配置，以 CSS 顯示對應封面。

所有原有遊戲路徑與玩法維持；單字樂園說明更新為六主題、60 字、中英文發音。桌面與手機均採兩欄小卡，手機檢查 390px、320px 寬度的圖像比例、文字換行與橫向溢出；卡片整體可點選。

驗證：npm run build 全部測試通過；首頁 12 個遊戲連結與四份新圖片正式站內容比對。
