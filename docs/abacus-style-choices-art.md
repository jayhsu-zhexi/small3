Final prompt:

Create a single horizontal UI sprite atlas, aspect ratio 3:1, exactly three equally sized square tiles in one row with straight clean boundaries. For a premium Taiwanese wooden abacus learning game. Each tile shows a front-on miniature abacus, walnut frame, champagne brass horizontal bar and rods, glossy deep burgundy red beads, dark forest green felt, warm cream background, handcrafted polished realistic 3D material, clean readable silhouette. Left tile exactly 5 vertical rods; middle exactly 7 vertical rods; right exactly 9 vertical rods, with last two rods subtly amber and a small luminous decimal dot between rod 7 and 8. One upper bead and four lower beads per rod, all at zero. Same bead size and rod spacing between tiles, so five rod model is narrower. No letters, words, numbers or logos, no external shadows crossing tile boundaries, no perspective tilt. Centered object with generous 12 percent margins. This is an asset sheet for three clickable style choices, not a full webpage.

Three equal atlas cells are displayed in real buttons. Labels and selection states are accessible HTML. Decorative image rods do not control game geometry. The live abacus uses a viewport-based rod pitch shared by all three modes; unit/thousand/million reference dots remain real components.
