# 太空救援：進場、通關與失敗

這次將太空圖片搭配短動畫與原創合成音效，並把時間選擇做成立體圖像按鈕。

## 實際行為

- 進場約 2.4 秒：火箭充能、光環加速、星光躍遷，最後卡牌依序展開。可隨時按右下角圖像按鈕略過，或按 Escape。倒數與翻牌在轉場完成後才啟用。
- 通關：太空站由暗轉亮，青綠光環與光粒向外擴散，搭配充能上升音和完成提示。
- 失敗：完整的太空站切換為備援燈光，琥珀色光環收縮，搭配降頻斷電音與柔和訊號提示。
- 結果畫面的重新挑戰與選擇難度可立即操作。重新開始、略過、切換分頁都會清理先前的聲音。
- 系統設定減少動態效果時，直接進入遊戲，結果圖片保持靜態。音效遵循既有音效開關，背景音樂仍有獨立開關。

## 時間設定

- 選擇不同卡牌數量，先帶入原本的建議時間：16 張 3 分、24 張 3 分 30 秒、32 張 4 分、40 張 4 分 30 秒、52 張 5 分。
- 圖像 −／＋ 每次調整 1 分鐘；碰到邊界停在 3 或 10 分鐘。保留建議時間中的半分鐘，例如 3:30 按＋成為 4:30，9:30 按＋停在 10:00。
- 10 分鐘再按＋為不限時，圖示改為 ∞；不限時按−回到 10 分鐘。
- 重新挑戰沿用目前時間；改選另一個卡牌數量會帶入該數量的建議時間。
- 不限時仍會消耗護盾，護盾耗盡仍會結束。通關只加護盾獎分，不計時間獎分。

## 圖像資產與生成紀錄

全部使用內建 imagegen，三個最終圖像各生成一次。原始 PNG 保留為母檔；網站使用相同尺寸的 WebP 壓縮版本，圖像按鈕以 CSS 定位原圖中的符號。圖片為不透明 RGB。兩張結算圖片在啟動任務後才載入，失敗時不影響結果與重試操作。

確切送出的 prompt、來源路徑與尺寸檢查：

- [通關與失敗 prompt](memory-result-scenes-prompts.json)

進場沿用既有的 `memory-home-v2.png` 太空場景與 `memory-controls.png` 火箭圖像，配合 CSS 光環和星光。結果背景以中央裁切適應桌機與手機；場景外緣的天線可能被裁切，主要太空站保持可辨識。

## 驗證

已檢查完整實際翻牌通關、手機護盾失敗、圖像按鈕的 3–10 分鐘與不限時切換、進場略過、圖片載入及可立即操作的結果按鈕。自動檢查涵蓋倒數在轉場期間停止、切換分頁暫停、重試取消舊結局、結局音效與圖片同步、獨立靜音、不限時仍能配對與護盾失敗，以及有限且正確的通關分數。
