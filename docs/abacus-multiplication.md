# 珠算乘法設定

自己出題新增「運算方式」選單（加減法／乘法），電腦出題原選單也增加乘法。選擇乘法時固定兩個數字，暫不混合加減、連乘或改變運算優先順序。加減題原本2～5口維持。

乘法的題幹、數字鍵盤預覽及清單統一顯示 ×，本機自訂題目可以儲存、重新載入、取消修改；先前加減題不受影響。自訂正數相乘，乘積不能超過目前檔數的上限。小數盤乘積超過兩位小數會拒絕，計算用整數精確驗證，避免靜默四捨五入。

電腦乘法用2以上的整數，乘積在選定範圍內，極端亂數與固定亂數都不會連續出現相同題。單題仍需撥珠後按確認，答錯持續重試。

口數與運算方式使用相同的44px高度、背景、9px圓角、16px字體，左右對齊。檢查手機390×700、電腦1440×900、iPad768×1024及1024×768，設定按鈕可見，主畫面維持一頁。也將既有高度調整延伸到較寬桌面，避免確認按鈕落到畫面外。

測試：test-abacus.cjs檢查整數／小數乘法、範圍及精度錯誤不破壞現有題目、極端亂數不重複、預覽、判斷、儲存、取消、2數字鎖定。瀏覽器實際完成12×7＝84，並開始電腦乘法組題。
