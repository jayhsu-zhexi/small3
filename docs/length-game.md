# 公分毫米小工坊

## 01｜使用方式

入口 `/length`，學習星球首頁有獨立卡片。四種題型：認識刻度、公分毫米換算、公分與毫米合併、生活應用。每輪 10 題不重複，首次以示意圖的「3 公分 6 毫米」開始；重練重新抽題。

數字鍵盤由左至右填數字。混合單位有公分、毫米兩格，點格選取後填入；電腦也可使用數字鍵、刪除鍵、方向鍵和 Enter。答案欄為唯讀，不叫出手機鍵盤。答錯保留輸入，可看提示、清除或重試；答對須自行按下一題。成果顯示完成數與未看提示、未重試的首次答對題數。

進度以 `small3-length-practice-v1` 獨立保存，音效開關以 `small3-length-sound` 保存，與既有遊戲分開。無法保存或播放音效時仍可繼續答題；損壞存檔恢復新一輪。切換有答題紀錄的輪次前顯示確認視窗。

## 02｜尺規與教學

所有數值以整數毫米運算。SVG 程式繪製每毫米一小格、每公分十小格，第五小格加長；橡皮擦左右端與相同的數學座標對齊。讀刻度題前五題從零起點開始，後五題加入非零起點，後者以終點減起點計算。尺規僅供讀刻度，不代表裝置上的真實物理長度。

題目、刻度、答案與控制項均為程式內容，不使用示意圖中的文字或錯誤刻度。

## 03｜插圖來源

核准示意圖保留於 `docs/previews/length-reference.png`。使用內建 imagegen 參考該圖，分別產生三張透明插圖，再去除透明邊緣及壓縮為 WebP，未覆蓋既有遊戲素材：

| 插圖 | 生成提示重點 | 專案素材 |
| --- | --- | --- |
| 閱讀小熊 | 保留棕色圓耳、友善表情、坐姿、打開的綠色書本；只保留角色，透明背景、無文字與面板 | `assets/length-bear.webp` |
| 紫色橡皮擦 | 參考圖的薰衣草紫長條橡皮擦、圓角、右側紙帶；水平、緊密裁切、透明背景，不含尺規、數字、陰影 | `assets/length-eraser.webp` |

背景以 CSS 奶油色漸層繪製，題目與尺規不需要新增點陣背景。答題音效沿用既有原創 Web Audio 模組。

## 04｜驗證

`node scripts/test-length.cjs` 覆蓋 1,000 題計算、100 輪不重複抽題、完整尺規刻度、零毫米與非零起點、重試與提示、合法與損壞存檔、第二個答案先填的保存、四種題型共 40 題實際控制邏輯、靜音及保存失敗，以及公開路由與全部素材位元組。

`npm run build` 全套既有測試及建置通過。瀏覽器實際完成十題混合單位，確認錯答重試、答對不自動跳題、答對重載、成果重載、返回及首頁入口；320×568、390×700 手機與 1024×768 平板橫向皆無頁面或題卡溢出。平板截圖 `docs/previews/length-tablet.png`。

## 05｜工程紀錄工具限制

本機讀取 engineering-convergence-loop 並執行 doctor 後，確認尚無 workflow.json。初始化由工具拒絕，原因為 Windows 不支援其要求的 cooperative file lock；未建立或手寫 workflow.json，未宣稱工程流程 Gate 通過，也未修改 Skill、全域設定或其他 framework。功能以專案既有測試與建置流程驗證。

## 06｜生活題先讀題換算

生活應用題在未答對前不顯示尺規、橡皮擦與尺規註記，也不繪製數值刻度或提供終點的無障礙描述。看提示、答錯與未答對重載仍隱藏；答對才顯示尺規驗證，重載保留已揭露狀態，下一題重新隱藏。其餘三種題型維持原本尺規呈現。

## 07｜首頁尺規封面

首頁卡片使用獨立 length-cover.webp，主體為黃色尺規與紫色橡皮擦，背景沿用奶油色教室。以內建 imagegen 原創生成，提示指定尺規占主要畫面、粉彩文具、無文字、無人物；壓縮至 800 像素寬 WebP。這張圖僅為遊戲封面，實際答題尺規仍由 SVG 精準繪製。
