# 公分毫米小工坊

## 更新｜認識刻度分為從 0 開始與不是從 0 開始

題型選單分開「認識刻度｜從 0 開始」和「認識刻度｜不是從 0 開始」兩類。從 0 開始的一輪十題全都從 0 量；不是從 0 開始的一輪，前五題練整公分，後五題加入毫米。公分毫米換算、合併與生活題維持原規則。

不是從 0 開始的題目，學生依序選出藍色左端起點、橘色右端終點，接著直接看到「終點 − 起點＝□」並填答，不強制數距離，也不預先提供長度答案。需要時按「看提示」才開放逐段亮起距離的按鈕；看提示會正常記入學習紀錄，並可隨時回到填答。答錯終點讀值時，明確提醒不能把終點直接當長度。

端點重選、選用的數格提示進度、答案與錯誤次數沿用原本存檔保存。舊版尚在強制數格步驟的進度會直接接續減法填答；舊版混合起點的認識刻度存檔，移回從零測量但保留各題長度、答案與完成紀錄。手機用兩欄大按鈕選端點，平板用四欄，數距離按鈕至少 44px。

驗證：五種題型整輪、全部 60 種新題、起終點誤選、填答限制、數距離進度重載、錯誤存檔、終點誤填的說明，以及新一題重置，均納入 `scripts/test-length.cjs`。

## 01｜使用方式

入口 `/length`，學習星球首頁有獨立卡片。五種題型：認識刻度｜從 0 開始、認識刻度｜不是從 0 開始、公分毫米換算、公分與毫米合併、生活應用。每輪 10 題不重複，首次以示意圖的「3 公分 6 毫米」開始；重練重新抽題。

數字鍵盤由左至右填數字。混合單位有公分、毫米兩格，點格選取後填入；電腦也可使用數字鍵、刪除鍵、方向鍵和 Enter。答案欄為唯讀，不叫出手機鍵盤。答錯保留輸入，可看提示、清除或重試；答對須自行按下一題。成果顯示完成數與未看提示、未重試的首次答對題數。

進度以 `small3-length-practice-v1` 獨立保存，音效開關以 `small3-length-sound` 保存，與既有遊戲分開。無法保存或播放音效時仍可繼續答題；損壞存檔恢復新一輪。切換有答題紀錄的輪次前顯示確認視窗。

## 02｜尺規與教學

所有數值以整數毫米運算。SVG 程式繪製每毫米一小格、每公分十小格，第五小格加長；橡皮擦左右端與相同的數學座標對齊。從 0 開始的認識刻度題，全輪皆從零起點開始；非零起點另列獨立題型，以終點減起點計算。尺規僅供讀刻度，不代表裝置上的真實物理長度。

題目、刻度、答案與控制項均為程式內容，不使用示意圖中的文字或錯誤刻度。

## 04｜驗證

`node scripts/test-length.cjs` 覆蓋 1,000 題計算、100 輪不重複抽題、完整尺規刻度、零毫米與非零起點、重試與提示、合法與損壞存檔、第二個答案先填的保存、四種題型共 40 題實際控制邏輯、靜音及保存失敗，以及公開路由與全部素材位元組。

`npm run build` 全套既有測試及建置通過。瀏覽器實際完成十題混合單位，確認錯答重試、答對不自動跳題、答對重載、成果重載、返回及首頁入口；320×568、390×700 手機與 1024×768 平板橫向皆無頁面或題卡溢出。平板截圖 `docs/previews/length-tablet.png`。

## 05｜工程紀錄工具限制

本機讀取 engineering-convergence-loop 並執行 doctor 後，確認尚無 workflow.json。初始化由工具拒絕，原因為 Windows 不支援其要求的 cooperative file lock；未建立或手寫 workflow.json，未宣稱工程流程 Gate 通過，也未修改 Skill、全域設定或其他 framework。功能以專案既有測試與建置流程驗證。

## 06｜生活題先讀題換算

生活應用題在未答對前不顯示尺規、橡皮擦與尺規註記，也不繪製數值刻度或提供終點的無障礙描述。看提示、答錯與未答對重載仍隱藏；答對才顯示尺規驗證，重載保留已揭露狀態，下一題重新隱藏。其餘三種題型維持原本尺規呈現。

## 07｜首頁尺規封面

首頁卡片使用獨立 length-cover.webp，主體為黃色尺規與紫色橡皮擦，背景沿用奶油色教室。以內建 imagegen 原創生成，提示指定尺規占主要畫面、粉彩文具、無文字、無人物；壓縮至 800 像素寬 WebP。這張圖僅為遊戲封面，實際答題尺規仍由 SVG 精準繪製。

## 08｜醒目答題回饋

依核准的答對／答錯對照圖，將判定移到答案格正下方獨立橫幅：綠色勾號「答對了！你真棒！」及完整換算結果；橘色驚嘆號「再想一想！」及單位提醒；未填完則提示補齊並標記空格。錯誤格粗橘框、正確格綠框及勾號，使用 aria-invalid，回饋區提供 polite、atomic 狀態宣告。學生重新輸入、刪除或清除後收起舊橫幅；只選取答案格或看提示時保留錯誤標示。答對重載仍顯示綠色橫幅，下一題重新開始。

生活題仍先隱藏尺規，答對才揭露並標示「用尺規驗證看看」。既有答對／答錯語音及靜音設定維持原樣。短螢幕縮小尺規並收起裝飾區，保留答案、醒目橫幅、下一題及鍵盤。淡入動畫遵守 prefers-reduced-motion。

## 題號燈與非零起點測驗

完成一輪後播放使用者選定的 H「歡樂過關」原創旋律（length-complete-h-v1.wav）。第十題確認並完成時自動觸發一次；重載不自動播放，沿用靜音設定，切換練習、靜音、背景或離頁時停止。

尺規距離顯示改為答對後按「驗證」，一次亮起整段正確長度並顯示終點減起點的算式；答題前的提示不再提供逐段亮格按鈕。驗證不影響既有首次答對、提示或錯誤紀錄，舊存檔中未答對時的亮格會清除。

題卡標題下保留一條細列，每題以小圓燈顯示題號。綠燈表示首次答對，紅燈表示曾答錯，重試成功仍保留紅燈；灰燈表示尚未作答。作答紀錄沿用既有儲存，重新開啟仍保留。未填答案不算錯，分步練習選錯起點或終點則算錯。小手機縮短提示區與鍵盤高度，維持單頁操作。

「不是從 0 開始｜測驗」包含五題公分、五題毫米混合排列，不提供提示或減法式。每題按確認答案立即公布對錯、燈號與語音，答錯留在同題、可持續重試，答對後才能按下一題；紅燈與分數保留首次作答紀錄，十題後自動顯示總分、解答及熊熊拉炮通關動畫。未填完整不計分、不換題，重新開啟保留已評分結果。舊版尚未交卷的存檔保留各題草稿，回到第一題開始逐題確認；舊版已交卷的成績仍保留。

通關慶祝共用 completion-party.js/css，沿用原本小熊美術，66 片彩帶，H 音樂預先載入，熊熊出現時立即播放，移除原本等待拉炮的前奏靜音；播放仍直接由 iPad 點擊事件觸發。第十題後自動進成果頁並開啟慶祝視窗，約 5 秒收起，亦可按看成果或 Escape 關閉。靜音仍顯示動畫，降低動態效果設定減少位移，重載不重播；重開、離頁與背景會停止並清理。

測驗答錯不鎖定輸入、不揭露正確答案、不開放換題；重答成功保留紅燈，得分依首次是否答對計算。第十題必須答對才完成並觸發通關。單次作答舊存檔中的首個錯題會重新開放作答，後續答案以草稿保留。

測驗換到新題目時一律清空輸入，不再從舊輪次的答案預填。一次遷移會清除舊版尚未確認的自動預填與後續題目草稿；本次手動輸入、當前錯誤嘗試與已評分燈號保留。
