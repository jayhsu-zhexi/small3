# 地理探險任務（臨時段考遊戲）

本機入口：`http://127.0.0.1:4174/geography`，執行 `node scripts/serve.cjs --port 4174`（`npm run dev` 預設為 4173）。

依 `docs/previews/geography-reference.webp` 製作，背景由原示意圖以 ImageGen 移除文字及控制項後產生，再轉成 WebP。地圖、經緯線、標記、按鈕和文字皆為可互動的 HTML / SVG。

目前五站各 8 題，共 40 題：位置與方向、經緯度定位、地圖判讀、臺灣的位置、生態與交流。後兩站依康軒七上第二課「位置對臺灣的影響」新增，題型卡標示「康軒第2課」。每次進入先顯示五種題型選單，選好才載入題目；上方可返回選單，保留既有進度；學校實際段考範圍仍待確認。

進度獨立存在 `small3-temporary-geography-v1`，包含完成題目、首次獨立答對、提示與重試紀錄，不併入原學科、樂園或備份。

題庫版本 3：全部 24 題改為進階題，包含旋轉指北標、更換觀察起點、多段位移、跨赤道緯度差、較小經度夾角、座標條件定位、反推比例尺、地圖放大、相同圖幅面積比與步行時間。每題四個選項，保留提示、重試與完整解釋；地圖同步顯示每題的指北標方向，以及跨南北半球與東西經的座標。

第二課擴充維持原題庫的前 24 題及 `bankRevision:3`，新增索引 24–39、`lesson2Revision:1`。原版完成、提示與錯題紀錄直接保留，新增題另行完成；原先全破的學生可從題型選單選擇第四站，不需要重新開始。進度總數改為 40，新增兩枚徽章；手機選單直列顯示題型、內容重點及完成進度。

第二課題目涵蓋區域航程、臺灣本島經緯度、北回歸線、本島與離島、行政區層級、不同海拔的棲地、冰河期遷徙、特有種、候鳥中繼站與國際貿易。使用原創題目與 SVG 示意圖，包含東亞區域圖、棲地、海面變化、自然分布表及進出口流程；區域海岸輪廓為簡化示意。

課名與範圍參考（查核日期 2026-10-09）：[康軒 115(1)國中社會1上測驗卷出版目錄](https://www.pubu.com.tw/ebook/686976)、[屏東潮州國中公開課程計畫](https://www.cp.ptc.edu.tw/storage/134522/134522_110_B-1_7A.pdf)。位置資料核對[水利署臺灣海岸詳介](https://www.wra.gov.tw/News.aspx?n=3253&sms=9088)；生態概念核對[臺灣國家公園隔離演化說明](https://www.taiwan.nps.gov.tw/home/zh-tw/quarterly/7959/7383)、[太魯閣生物多樣性](https://www.taroko.gov.tw/ch/sglarticle/biodiversity)；行政區關係核對[板橋區公所](https://www.banqiao.ntpc.gov.tw/home.jsp?id=8c4540120c916d8b)。課程計畫用於概念範圍對照，非學生所在學校本年度的考試範圍。

重新載入、切換任務與下一題只接續未完成的題目；完成的站顯示成果，全程完成後需確認重新開始才會重玩。版本 1、2 的舊存檔會把答案、提示與錯題存入 `previousRounds`，新版另計進度並顯示升級說明及舊版完成題數。新版重新開始也保留舊版成果；其他遊戲的儲存鍵不變。

日後移除：刪除 `geography.html`、六個 `assets/geography-*` 檔案；移除 `index.html` 中 `/geography` 卡片、`scripts/build.cjs` 的 geography files.push、`scripts/serve.cjs` 的 geography 路由、`vercel.json` 的兩條路由及排除項、`package.json` 的地理測試及 `scripts/test-geography.cjs`。最後執行 `npm run build`。本機遺留的獨立進度不影響其他遊戲。
