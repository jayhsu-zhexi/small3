三個主題、30 個單字，每次認識 5 個，再完成 10 題看圖／聽音練習。無計時、不扣分，可重複發音，完成後收集貼紙。進度只儲存在目前瀏覽器，不同步帳號，也尚未納入既有進度備份。

插畫由內建 ImageGen 產生，角色、場景與物件分離，程式控制互動、動畫與所有文字。原始 PNG 保留於 Codex generated_images；專案使用 WebP。狐狸圖第三格附帶寶箱。顏色使用可辨識的 CSS 色球。

發音由 Windows Microsoft Zira Desktop（en-US，Rate=-1）生成 22.05 kHz、16-bit mono WAV。正常速度 1；慢速 .75，保留音高。播放失敗可看文字提示。共 29 份音檔，水果與顏色的 orange 共用發音。
