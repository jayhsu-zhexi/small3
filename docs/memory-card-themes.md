# 卡牌外觀選擇

首頁以三組實際卡背與道具卡面展示 A「金屬反應爐」、B「水晶能源」、C「太空裝備艙」。初次進入預設 C；點選後即時顯示亮框與勾選，開始任務會套用該款卡框與卡背。

偏好僅儲存在同一瀏覽器、同一網站的 `learning-planet-memory-theme-v1`。無效值回到 C；禁止儲存時仍可正常切換和遊玩。它是外觀偏好，不包含遊戲進度，也不加入學習紀錄備份。

26 種圖像道具共用同一套配對內容。A 採銀色拉絲金屬與青色燈邊，B 採藍紫水晶與金色能源，C 採白色陶瓷、鈷藍艙體與橘色護角。道具使用相同的立體收藏模型，避免不同外觀改變符號辨識與難度。

卡面僅呈現圖像。朗讀標籤仍保留中文道具名稱；未翻開時只讀取卡牌位置，配對後加上「已配對」。成功後卡框與道具淡化至 24% 不透明度並降低彩度，保留較淡的小勾號，位置固定以便記憶。保留 3D 翻轉、成功粒子、失敗橘色光暈與叉號，以及減少動態效果設定。

首頁新增「選擇卡牌外觀」及「點選圖片切換外觀，會記住你的選擇」提示。

首頁預先載入三張卡牌圖集，準備好後才能開始倒數。載入失敗或超過 20 秒會提示點火箭重試，不扣遊戲時間。

## 生成素材

使用 imagegen 內建工具，以使用者選定的三張概念圖為風格參考。工具產生的透明背景及背景移除版本均仍帶有不透明方格，因此最終道具改為深藍底的嵌入式裝備面板；沒有用程式修改影像。卡框以 CSS 背景定位及圓角裁切到實際邊緣，方格區不會顯示。完整生成及編輯提示詞保存在 `docs/memory-card-themes-prompts.json`，包含未採用的去背紀錄。

- `assets/memory-card-shells.png`：三款卡背及空卡框。
- `assets/memory-equipment-1.png`：道具 1–13，包括推進器、衛星、晶片、護盾、探照燈、電池、電台、軌道儀、反應爐、磁力器、溫度計、晶礦與燃料。
- `assets/memory-equipment-2.png`：道具 14–26，包括密鑰、氣閘鎖、扳手、雷達、天線、硬碟、太陽能、月岩、望遠鏡、試劑、顯微鏡、接頭與電路板。

圖集以 CSS 定位顯示，保留工具輸出的 PNG 檔案，不以其他影像工具重製。遊戲規則、計分、倒數及護盾機制維持原設計。

## 驗證

自動驗證包括預設與儲存外觀、禁止儲存、26 種圖像唯一性、同組圖像一致、圖片等待／重試／逾時，並覆蓋五種卡數、計分、生命值、暫停、重新開始和音效。正式打包會驗證新素材與其他遊戲的所有公開路徑。

「＋」模式新增 4 種道具，共 30 種，載入必要圖集改為 4 張。新增素材及生成提示詞見 `memory-plus.md`。
