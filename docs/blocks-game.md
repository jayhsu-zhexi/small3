# 方塊消消樂

入口 /blocks，首頁已加入遊戲卡片。依 docs/previews/blocks-reference.png 實作奶油色、糖果色方塊、藍色棋盤框、右側資訊卡及五個底部按鈕。

背景由內建 imagegen 以原示意圖編輯，保留左側貓咪、書本、右側植物與筆筒，移除所有 UI 和文字。提示詞要求背景中央 70% 留白、奶油色與柔和插畫質感。產物轉為 assets/blocks-background.webp（1536×1024，約 38KB）；棋盤與按鈕為即時 canvas 與 HTML。

10×20 棋盤，七種四格方塊，七袋抽選、順時針旋轉和牆／底部退讓、落點預覽、500ms 鎖定延遲、1–4 排消除動畫與計分，每 10 排增加速度。觸控長按左右／下降，鍵盤左右上下／空白鍵／P。暫停或切換視窗時停止更新；重新開始需確認，最高分保存在獨立儲存鍵 small3-candy-blocks-best-v1。儲存不可用仍可玩。

測試：引擎測試四向旋轉、邊界、時間、清除與分數、遊戲結束及 100 局隨機操作；UI 測試觸控重複／取消、鍵盤、暫停、隱藏頁面、重開與取消、結束再玩及儲存失敗。瀏覽器檢查 1024×768 平板、390×844／320×740 手機與 844×390 橫放；正式部署前執行完整 npm run build。
