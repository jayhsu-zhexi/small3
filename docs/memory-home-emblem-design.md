# 首頁圖像標誌與導航

首頁主標題改成 imagegen 生成的立體「失聯／太空站」標誌。字面採白金金屬，搭配金色邊緣、藍色發光層次與軌道裝飾。

原本任務說明改成「成對卡牌 → 能源 → 點亮太空站」圖解；導航以反應爐、喇叭、問號與出口圖片呈現。首頁常駐文字僅保留圖片中的名稱及必要數字，所有功能保留中文替代文字、輔助標籤與滑鼠提示。喇叭可以切換音效，問號開啟完整玩法。

素材使用 imagegen 內建生圖產生，每項一次，保留透明度：

- `assets/memory-title.png`：1448 × 1086 的標誌。
- `assets/memory-home-icons.png`：1536 × 1024 的六格圖集，依序為太空站、反應爐、喇叭、問號、出口與閃電。
- `docs/memory-home-emblem-prompts.json`：兩項素材的完整生成提示詞。

卡片 A／B／C 設計仍是待選提案，保存在 `outputs/memory-card-options/`，尚未套用至遊戲卡牌。
