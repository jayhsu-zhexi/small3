## 功能與教學

暖身練習、進位挑戰、三位數挑戰、生活應用，每輪10題不重複。首次預覽24×3，後續新一輪重新抽題。題型依三年級 N-3-3 二、三位數乘一位數安排，含三位數十位為0，實際學校進度依課本另確認。

直式由個位向左填入，每格數字獨立；進位格可不填，若填入則檢查是否正確。可使用大數字鍵盤或實體鍵盤；手機數字鍵盤固定底部，不喚起另一套螢幕鍵盤。提示按位說明，包含上一位的進位，答錯可重試且保留輸入。答對須按下一題，全部完成後顯示成果；提示／重試不計獨立首次答對。切換已作答的輪次需確認，獨立 localStorage 儲存鍵 small3-multiply-practice-v1，壞存檔回復新一輪，儲存失敗仍可練習。

## 生活應用先列式

生活題先只顯示題目及兩個空白數量欄，不顯示直式或帶數字的筆盒。學生用自訂鍵盤填入兩個因數，確認列式後才進入直式。接受題目兩個數量的交換順序；僅答案乘積相同但非題目數量的組合不通過。列式提示只引導找出每盒枝數與盒數，不公布數字。錯誤列式計入該題重試次數，提示計入協助紀錄，列式成功不算已完成題目。

每題保存列式草稿與階段，下一題重置列式。舊版生活題已開始的直式／已完成成果會遷移保留；尚未開始計算的題目改由列式開始。兩個數量欄維持 readOnly，手機不叫起原生鍵盤，電腦仍可用數字及刪除鍵。

完整 npm run build 通過，新增未填／錯誤／交換因數／續存／下一題／舊存檔遷移測試；瀏覽器實際驗證列式後計算，以及 320×568 手機頁面與題卡均無溢出。示例截圖 docs/previews/multiply-story-formula.png。

## 答题音效

加入原創 Web Audio 提示音：答對為三段上揚音，答錯為兩段柔和下降音，列式正確／錯誤也有回饋。只在確認有效答題時播放，未填完、重載及換題不播放。音效預設開啟，可用數字鍵盤標題右側的開關靜音；設定以 small3-multiply-sound 獨立保存。

AudioContext 在使用者按確認後才建立／恢復。連續確認會停止前一次聲音，靜音及切至背景會取消尚未恢復的播放，離開釋放音訊資源，瀏覽器返回快取頁面可重新建立。缺少音訊支援或播放被阻擋仍可正常答題。新增音訊排程、取消恢復、失敗降級、答題觸發及靜音保存測試。
